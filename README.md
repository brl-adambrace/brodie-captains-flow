# Brodie — Captain's Flow Prototype

Interactive prototype of the new Captain registration flow for join.brodierec.com.

- Full flow: https://brl-adambrace.github.io/brodie-captains-flow/
- Uniform selection only (for engineering): https://brl-adambrace.github.io/brodie-captains-flow/uniform/

Open a live link, or open `index.html` in any browser. In the full flow, press the backtick key (`) to show the dev toolbar and jump to any screen or state. The uniform page shows its toolbar by default, with preset states and a live readout of the ranked picks.
